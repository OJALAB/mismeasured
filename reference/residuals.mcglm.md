# Residuals for an `mcglm` fit

Residuals for an `mcglm` fit

## Usage

``` r
# S3 method for class 'mcglm'
residuals(
  object,
  method = NULL,
  type = c("response", "pearson", "deviance"),
  ...
)
```

## Arguments

- object:

  An `mcglm` object.

- method:

  Estimation method.

- type:

  One of `"response"`, `"pearson"`, `"deviance"`.

- ...:

  Unused.
