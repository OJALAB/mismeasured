# Summary of an `mcglm` fit

Returns a Wald-style coefficient table (estimate, standard error,
z-value, p-value) for each fitted method, using the asymptotic sandwich
variance derived in Battaglia et al. (2025).

## Usage

``` r
# S3 method for class 'mcglm'
summary(object, ...)
```

## Arguments

- object:

  An `mcglm` object.

- ...:

  Unused.
