# Proxy design matrix used by `mcglm`

Returns the assembled \\\hat\xi_i = (\hat d_i, x_i)\\ design matrix
(proxy-encoded misclassified covariate plus other covariates).

## Usage

``` r
# S3 method for class 'mcglm'
model.matrix(object, ...)
```

## Arguments

- object:

  An `mcglm` object.

- ...:

  Unused.
