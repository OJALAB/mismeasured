# Normalize a GLM family specification

Normalize a GLM family specification

## Usage

``` r
.normalize_family(family, env = parent.frame())
```

## Arguments

- family:

  A [`family`](https://rdrr.io/r/stats/family.html) object, family
  function, or character string naming a family function.

- env:

  Environment in which to resolve a character family name.

## Value

A standard `family` object.
