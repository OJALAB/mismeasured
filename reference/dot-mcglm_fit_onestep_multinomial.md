# One-step joint estimator for multinomial logistic with misclassified covariate

One-step joint estimator for multinomial logistic with misclassified
covariate

## Usage

``` r
.mcglm_fit_onestep_multinomial(
  y,
  z_hat,
  x,
  J,
  K,
  p01 = NULL,
  p10 = NULL,
  pi_z = NULL,
  Pi = NULL,
  fix_omega = FALSE,
  optim_control = list(),
  wt = NULL
)
```
